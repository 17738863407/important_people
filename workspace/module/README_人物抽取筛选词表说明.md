# 人物抽取筛选词表说明

本目录当前只保留五类人物抽取筛选词表。

这些词表的定位是：**弱结构候选过滤工具**。它们不得成为强结构页面解析器的全局依赖。

## 保留词表

```text
黑名单_姓名_包含词.txt
黑名单_姓名_精确词.txt
黑名单_职务_精确词.txt
黑名单_职务_包含词.txt
白名单_弱结构职务提示词.txt
```

## 使用边界

### 强结构解析器

强结构包括：

```text
明确姓名列、职务列
明确人物卡片字段
明确详情页字段
明确接口 JSON 字段
```

强结构解析器必须以 DOM、表格列、卡片字段或 JSON 字段为准，**禁止依赖黑名单和白名单过滤结果**。

### 弱结构解析器

弱结构包括：

```text
姓名、职务、分工、简历混在同一段文本中
相邻文本块需要判断姓名和职务关系
正文详情页需要从长文本中识别职务
图片 OCR 或大模型抽取结果需要排噪
```

弱结构解析器允许使用本目录五类词表。

## 词表含义

### 黑名单_姓名_包含词.txt

候选姓名中只要包含其中任一关键词，即排除该候选姓名。

该文件由以下旧词表归并而来：

```text
黑名单_姓名包含词.txt
黑名单_姓名机构结尾词.txt
```

### 黑名单_姓名_精确词.txt

候选姓名正好等于其中任一关键词时，排除该候选姓名。

该文件由以下旧词表改名而来：

```text
黑名单_姓名精确词.txt
```

### 黑名单_职务_精确词.txt

候选职务正好等于其中任一关键词时，排除该候选职务。

该文件由以下旧词表改名而来：

```text
黑名单_职务精确词.txt
```

### 黑名单_职务_包含词.txt

候选职务中只要包含其中任一关键词，即排除该候选职务。

该文件由以下旧词表改名而来：

```text
黑名单_职务包含词.txt
```

### 白名单_弱结构职务提示词.txt

只用于弱结构邻近配对，帮助判断某段文本是否像职务。

强结构字段、明确表格列、明确卡片字段、明确 JSON 字段不得依赖该白名单。

如特殊复杂页面需要类似规则，应写入该页面脚本的 `parse_page()`，或写入特定弱结构解析器版本中，不再恢复为全局通用词表。
